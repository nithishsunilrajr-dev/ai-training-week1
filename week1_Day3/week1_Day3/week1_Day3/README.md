Week 1 - Day 3: Python & Data Engineering

Project Overview

This project covers fundamental Python data engineering tasks using NumPy and Pandas.

Topics Covered

1. NumPy Arrays

- Creating arrays and checking their shape, data type, and size
- Indexing and slicing
- Calculating averages
- Broadcasting and weighted scores
- Reshaping arrays

2. Pandas DataFrames

- Loading CSV files
- Inspecting data with "head()", "info()", and "describe()"
- Selecting columns and rows with "loc" and "iloc"
- Filtering employees by salary and department

3. Data Cleaning and Aggregation

- Detecting missing values and duplicates
- Filling missing values with the median
- Converting data types
- Grouping records and calculating totals

4. Merging Datasets

- Inner joins
- Left joins
- Outer joins
- Identifying unmatched records

5. Bonus Challenges

- Reshaping a 1-D array into a 3-D array
- Combining monthly datasets with "pd.concat()"

Files

- "day3_numpy_pandas.py" — NumPy and employee DataFrame exercises
- "day3_data_cleaning_merging.py" — Data cleaning, aggregation, and merging
- "employees.csv" — Employee dataset
- "orders.csv" — Order dataset
- "customers.csv" — Customer dataset

Requirements

- Python 3
- NumPy
- Pandas

Install dependencies:

python -m pip install numpy pandas

How to Run

python day3_numpy_pandas.py
python day3_data_cleaning_merging.py

Learning Outcome

Practiced array operations, DataFrame manipulation, missing-value handling, aggregation, and dataset merging using Python.s
