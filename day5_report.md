Employee Data Analysis — Day 5 Project Report
Problem Statement
The aim of this project is to understand employee salary distribution across different departments and cities using Python. The project also covers data cleaning and basic data visualization.
Dataset
The dataset contains 8 employee records with five columns: employee ID, name, department, salary, and city.
During data cleaning, no missing values or duplicate records were found. The cleaned dataset was saved as clean_data.csv.
Key Findings
Department Salary: Finance has the highest average salary at ₹90,000, while Sales has the lowest at ₹41,000.
Employee Distribution: Chennai has the highest number of employees, with 4 out of 8 records.
Salary Range: The lowest salary is ₹30,000 and the highest is ₹90,000.
Recommendations
Review salary differences across departments to understand whether they reflect job responsibilities and experience.
Collect more employee records for a more reliable salary comparison.
Limitations
The dataset contains only 8 employees, so the findings cannot be generalized to a larger organization. Department budget figures used in the analysis are illustrative rather than actual company data.
Conclusion
This project helped demonstrate how Python, Pandas, and Matplotlib can be used to clean employee data, calculate statistics, and create charts to support basic business analysis.
